# 내부 vLLM 엔드포인트

**목적지는 `.env` 의 `VLLM_BASE` 하나뿐이다.** KT Cloud AI Nexus 의 관리형 vLLM
(`gemma-4-31B-it`, OpenAI 호환 `/v1`). 근거는 ADR-018, 엔드포인트 성질은 ADR-019.

- **URL 자체가 자격증명이다** (MARA ADR-010). 인증을 요구하지 않아 주소를 아는
  주체가 곧 사용할 수 있는 주체다. `config.yaml`·코드·`.env.example`·커밋 메시지·
  ADR 본문 어디에도 적지 않는다. `.env` 로만 주입한다.
- 같은 값이 **MARA `.env` 에도 있다.** 두 파일 다 `.gitignore` 대상이라 동기화
  장치가 없다 — 한쪽이 바뀌면 다른 쪽은 조용히 옛 값을 쓴다.

## 🔴 이 서버는 모르는 파라미터를 조용히 무시한다

**400 이 오지 않는다. 경고도 없다. HTTP 200 이 오고, 그 파라미터가 하려던 일만
일어나지 않는다.** structured output 은 파라미터로 켜는 기능이므로, 이 성질은
**"강제가 꺼져 있는데 성공한 것처럼 보이는 상태"** 를 만든다 (ADR-019).

| 파라미터 | 이 엔드포인트에서 |
|---|---|
| `response_format={"type":"json_schema", ...}` | ✅ **강제됨. 이 레포는 이것만 쓴다** |
| `structured_outputs={"json": ...}` | 강제됨 (쓰지 않는다 — 하나로 고정) |
| `guided_json=...` | ⛔ **무시됨.** vLLM 문서에 흔히 나오는 이름이라 검색으로 흘러 들어오기 쉽다 |
| 존재하지 않는 이름 | 무시됨. `guided_json` 과 **결과가 같다** |

- **파라미터를 여러 개 같이 보내지 않는다.** 무엇이 동작했는지 알 수 없게 되고,
  서버가 바뀌었을 때 **언제 강제가 사라졌는지도 알 수 없다.**
- **오타가 조용히 통과한다.** 이 규칙은 그것을 없애지 못하고 알고 쓰게 만들 뿐이다.
  파라미터 이름은 `extraction/vllm.py` 한 곳에서만 만든다.

## 강제 여부는 "JSON 을 쓰지 마라"로 판별한다

⛔ **"스키마를 어겨 보라"로 판별하지 않는다.** 그렇게 짜면 **모델의 순종도와
디코더의 강제가 섞여** 정반대 결론이 나온다. 실제로 첫 probe 가 그랬다 —
`minLength` 가 문자열을 못 닫게 강제해서 깨진 JSON 이 나왔는데, 그것이 "문법이
뚫렸다"로 읽혔다. 원인은 정반대였다.

```
프롬프트: "JSON 을 쓰지 마라. 중괄호도 쓰지 마라. 한국어 산문 두 문장으로 답하라."
스키마  : {"답": {"type":"string","enum":["예","아니오"]}}  required
```

- **산문이 나오면** → 강제가 아니다. 모델이 지시를 따른 것뿐이다.
- **스키마에 맞는 JSON 이 나오면** → 강제다. 모델은 따르려 했는데 **나갈 수 없었다.**

강제와 순종이 **서로 반대 방향**을 가리키게 만든 것이 이 설계의 값이다. 결과가
어느 쪽이든 원인이 하나로 특정된다.

## 언제 다시 확인하나

**한 번 확인한 사실이 계속 참이라고 가정하지 않는다.** 관리형 엔드포인트라 서버
버전·빌드 옵션이 통보 없이 바뀌고, 바뀌어도 실패 신호가 없다.

- 엔드포인트 주소·모델·서버 버전이 바뀌면 **반증 probe 를 다시 돌린다.**
- 측정(대조 실행, eval)을 시작하기 전에 확인한다. 호출 1건이다.
- 스키마에 큰 `minLength`/`minItems` 를 넣으면 **절단 위험**을 같이 본다 —
  모델 능력과 무관하게 `finish_reason: "length"` 로 실패율이 오른다.

## 실패를 한 칸에 넣지 않는다

강제가 켜져 있으면 스키마 실패가 세 갈래로 갈린다. 섞으면 수치가 모델이 아니라
다른 것을 잰다 (ADR-018).

| 갈래 | 뜻 |
|---|---|
| 문법 밖 출력 | **구조상 불가능.** 나오면 모델 실패가 아니라 **강제가 꺼진 것**이다 |
| 수량 제약 위반 (pydantic 이 거부) | 모델 능력 / 프롬프트 |
| 절단 (`finish_reason == "length"`) | **디코딩 설정**(`max_tokens`)이지 모델 능력이 아니다 |

`export/replay.py` 가 건별로 `finish_reasons` 를 남긴다. 실패율을 셀 때 이 칸을
먼저 본다.

## 벤더 게이트와의 관계

**이전이 끝나도 `.claude/rules/external-llm.md` 의 게이트는 필요 없어지지 않는다.**

되돌아간다. 되돌리는 것은 설정 변경이 아니라 **전제 변경**이다.
