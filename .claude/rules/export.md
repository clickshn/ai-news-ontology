# 출력 계약 컨벤션
- 계약 전문은 **MARA 레포**에 있다 (`docs/contracts/ai-news-ontology-export-v1.md`).
  런타임에 읽지 않고 필요한 규칙을 복사해 고정한다 — 참조였다면 남의 레포의 상수
  변경이 우리 출력을 조용히 바꾼다.
- **`doc_id` 규칙과 URL 정규화는 계약에서 가장 되돌리기 비싼 부분이다** (§4).
  MARA 골든셋의 `expected_doc_ids` 와 인용 표기에 박혀 있어, 바꾸면 과거 측정값이
  전부 무효가 된다. 변경은 `contract_version` major 인상 사안이다.
- 형식을 바꿔야 하면 **계약 문서를 먼저 고친다.** 코드가 먼저 바뀌면 계약이 아니라
  우연이 된다.
- `record.py` 와 그 아래에서 **LLM 을 호출하지 않는다.** 재-export 경로에 API 가
  섞이면 계약 §12.3(형식 결함에 비용을 두 번 내지 않는다)이 무너진다.
- MARA 레포는 **읽기 전용**이다. 병합 시뮬레이션이 스냅샷을 읽더라도 쓰지 않는다.
