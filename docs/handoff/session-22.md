## 2. 사용자 요청과 다르게 적은 것 — 확인 필요

- **장애 복구 명령을 `pipeline run` 이 아니라 `pipeline scheduled` 로 적었다.** 요청은 "pipeline run
  수동 실행"이었지만, ① 10/12 복구 3회가 실제로 `scheduled` 모드였고(session-21 §1) ② `pipeline run` 은
  governance 상 **매 실행 6항목 게이트**이며 ③ 수동 `run` 은 **경보 상태를 갱신하지 않아** 열린 경보가
  닫히지 않는다(session-21 §2). `operations.md` §2 에 둘의 차이를 적어 두었다. `run` 으로 바꾸길 원하면
  그 문장만 고치면 된다
