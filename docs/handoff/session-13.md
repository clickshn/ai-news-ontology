**둘 다 10/10 같은 모양이다 — 흔들림이 아니라 체계적 규칙 이탈이다.** judge 는 요소 판정에서는
"이름만은 담김이 아니다"를 지키고, 슬롯 판정에서 다시 "일부 담김"처럼 올린다.

- **H5 미달은 "표를 안 따랐다"가 아니다.** 사후 지표(D-095)가 없었으면 반대로 읽었다.
- **#33001 은 H5 를 통과했는데 더 나쁜 경우다.** 지표가 통과를 말하는 자리에서 규칙이 어겨졌다.
- 사전 등록 기준을 데이터를 본 뒤에 완화하지 않았다 (D-065). **점수 일치는 전환 조건이 아니다.**

### #33001 ② 의 "담김 vs 이름만" 경계 — 흔들리지 않는다

`이름만` **10/10.** v5 의 남은 비결정성으로는 관측되지 않았다. 대신 **체계적으로 손계산(담김)과
다르다.** v5 는 "무엇이 핵심인가"를 라벨로 옮겼지만 "그것이 요약에 있는가"는 judge 판단으로 남고,
그 판단은 흔들리지 않고 **한쪽으로 기운다.** 흔들림이 없으니 눈에 덜 띈다.

요소 자체가 **복합**일 수 있다 — "신뢰할 수 없는 입력(.vpk 파일·스트림)을 여는 FFmpeg 연동
애플리케이션". 가이드의 "원자 단위"를 어겼을 가능성 → §9.

## 3. v4 는 **퇴화**로 죽었다 (D-093)

v4 팔이 #33001 에서 4회 연속 실패 → 사전 등록 중단 조건. **실패 사유가 남지 않았다**(D-092 로 수정).
진단 1회(2건) 원본:

```
finish_reason: length ×2   completion_tokens: 4000
content: '{\n  "faithfulness":' + "\n  " × 1996      ← 값은 한 글자도 없다
```

JSON 문법이 허용하는 **토큰 사이 공백을 모델이 끝없이 냈다.** 이전 분류로는 "절단"이었고 절단의
처방(`max_tokens` 상향)은 **무효**다. v5 는 형식 **하나만** 바꿨고 퇴화 **0/33** — 여러 줄 형식
지시가 원인이었다는 근거가 하나 생겼다(추정이 아니게 된 것은 아니다 — v4 는 한 항목에서만 돌았다).

**교훈 두 가지:**

- **규모가 큰 호출을 단계로 쪼개지 않았다.** v4 는 30건을 한 번에 받았다. 3건 소표본이었으면
  1~3건에서 잡혔다. v5 는 F 소표본 → 결과 보고 → 본 실행 **별도 승인**으로 갔고, 사용자가 "통과하면
  바로"를 스스로 철회했다.
- **D-052 가 runner 에 걸려 있지 않았다.** predict 는 지키고 runner 는 안 지켰다 — session-09 의
  replay.py 건(D-077)과 같은 계열이다. 장치는 있었고 **모든 호출 경로에 걸려 있는지 확인하는 것이
  없었다.** 실패 분류(D-093)를 세 경로에 같은 함수로 건 것이 이 교훈의 적용이다.

## 주의 (이월 + 추가)

- 🆕 **handoff 가 들어오면 첫 줄 파일명을 본다.** `⚠️` 줄이 있으면 옛 handoff 가 바뀐 것이다.
- 🆕 **점수 일치를 판정 경로 일치로 읽지 않는다.** v5 가 3/3/3 을 맞히고 두 항목은 다른 경로였다.
- 🆕 **`finish_reason: length` 를 보면 `stop_kind` 부터 본다.** 퇴화면 `max_tokens` 를 올리지 않는다.
- 🆕 **구조화 출력 필드에 여러 줄 형식을 지시하지 않는다.**
- 🆕 **큰 호출은 소표본 → 결과 보고 → 본 실행 별도 승인.** "통과하면 바로"로 묶지 않는다.
- 🆕 **중단된 runner 결과 파일에는 summary 줄이 없다.** 원본은 `eval/scores/raw/judge-{run_id}/`.
- `judge_human_gap` 을 그대로 읽지 않는다 (D-087).
- 측정 전에 `python -m extraction.probe`. **날짜가 바뀌면 다시.**
- 실행에 쓰인 프롬프트 버전은 **수정하지 않는다** — v4 가 이번에 그 대상이 됐다.
- 테스트는 가상환경으로. 실제 Vault·`eval/scores/`·보존소에 쓰지 않는다.
- 변이 검사는 복사본에서. 셸 스크립트는 LF. push 전에 `git log --oneline`.
